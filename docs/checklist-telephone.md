# Checklist de test sur téléphone

À faire une fois par téléphone, avec l’app publiée sur https://django184.github.io/panier-temoin/. Noter le modèle et la version du système.

Appareil : ____________________  Système : ____________________  Date : __________

## 1. Installation et connexion

- [ ] L’app s’ouvre sur l’onglet Courses ; la barre du bas montre Courses, Carte, Ticket, Prix, Réglages.
- [ ] Installée sur l’écran d’accueil, elle s’ouvre en plein écran ; appui long sur l’icône (Android) : raccourcis Carte Cumulus et Liste de courses.
- [ ] Réglages → Se connecter : mauvais mot de passe refusé, bon mot de passe accepté, session gardée après fermeture.

## 2. Carte Cumulus

- [ ] Onglet Carte : le code-barres du numéro de carte s’affiche, avec le numéro dessous.
- [ ] L’écran ne s’éteint pas tant que la carte est affichée.
- [ ] En mode avion, la carte s’affiche encore.
- [ ] À la caisse Migros, le code-barres est lu et les points Cumulus sont crédités.

## 3. Courses et recettes

- [ ] Première ouverture : « Relier Chef Feta » et l’aide « Comment ça marche » s’affichent ; « Compris » masque l’aide.
- [ ] Dans Chef Feta, le lien « 🛒 Ajouter à ma liste de courses » ouvre l’app sur Courses, liste remplie, et fait apparaître l’onglet Recette.
- [ ] Cocher un article le barre ; « Modifier » permet de changer une quantité, retirer un article, en ajouter un.
- [ ] « Recettes » liste les recettes reçues ; toucher une recette la met dans la liste ou l’en retire (case cochée).
- [ ] Toucher deux fois le même lien de Chef Feta ne crée ni recette ni article en double.
- [ ] Un article retiré de la liste (Modifier → ×) apparaît grisé dans la recette, avec « + Liste » pour le remettre.
- [ ] Onglet Recette : − / + change les quantités affichées ; le bandeau « Adapter la liste » met la liste à jour.
- [ ] « Modifier » la recette : changer un ingrédient, enregistrer ; la liste propose l’adaptation.

## 4. Ticket

- [ ] Première fois : l’écran guide la liaison du projet Claude ; ensuite il ne montre que « Photographier le ticket ».
- [ ] Dans le projet Claude, la réponse à une photo contient le lien « Ouvrir dans Panier Témoin », qui ouvre la vérification, lignes remplies.
- [ ] Les valeurs incertaines sont surlignées ; « Envoyer le ticket » reste grisé tant qu’un point est à régler.
- [ ] Envoi : « Ticket enregistré » ; renvoyer le même ticket : « Déjà enregistré ».

## 5. Prix

- [ ] Onglet Prix : derniers achats avec leur écart (▲ hausse, ▼ baisse, = stable, nouveau).
- [ ] La recherche trouve un produit ; sa fiche montre la courbe, la comparaison des magasins et les promotions.

## 6. Réglages

- [ ] Désactiver « Aides » les masque partout ; les réactiver les montre toutes à nouveau.
- [ ] Un prix inhabituel met une pastille sur Réglages et apparaît dans « Prix à confirmer ».
- [ ] Mode sombre du téléphone : tout reste lisible ; la carte reste noir sur blanc.
